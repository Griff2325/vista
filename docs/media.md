# Explore and Spotify

## Explore

The Home Explore tile opens a native, Apple TV-inspired browsing screen: dark sidebar, a featured backdrop, a continuously loading title grid, visible D-pad focus, a local My list and installed-app banners. It keeps Android rendering and does not embed a web player or autoplay video.

**Free setup:** open Explore → Settings and enter a personal [TMDB read-access token or v3 API key](https://www.themoviedb.org/settings/api). TMDB requires its own account/API registration for personal non-commercial use. Vista does not create accounts, enroll in plans or purchase anything. The existing development TV had no catalog key configured when this refactor began; app shortcuts work without one. Keep keys out of source, screenshots and issue reports. Keys remain in private app preferences, sent only over HTTPS to their respective providers; Disconnect removes both. Android backup is disabled.

**Search across services:** title search spans TMDB movies and series and displays all reported US subscription, free and ad-supported offers, including providers outside the app-shortcut list. Without a service filter, it retains titles with no offer or failed availability lookup and excludes people from multi-search. An explicit service filter checks offers during search too; failed availability remains visible as uncertain rather than pretending it is unavailable. Choose **+ Filter** while browsing or searching to add services, genres, content type, an exact release year or a minimum TMDB user rating. Active filters appear as removable chips; Clear filters resets them. Genres include Action and Sci-Fi & fantasy, with existing saved genre/service indices preserved. Search keeps TMDB relevance order; browsing also offers popularity, top-rated and newest sorts. All services is the default mode. Selectable services include Netflix, Hulu, Disney+, Apple TV+, Prime Video, Max, Peacock, Paramount+, Tubi and Pluto; supported installed apps can be opened from title details. YouTube is an app/search shortcut outside this movie/series catalog. Search does not query each app's internal catalog, subscriptions or private viewing history. Rental/purchase offers are excluded; confirm access and subscription tier in the provider app. Provider actions try supported app search/open intents; TMDB does not provide universal title-specific playback links.

**Optional free ratings:** add an [OMDb free API key](https://www.omdbapi.com/apikey.aspx?at=freeAcct) in the same settings form. Its free account currently allows 1,000 requests per day; Vista does not require a paid plan. Ratings use the exact IMDb ID supplied by TMDB, not title guessing. IMDb and Rotten Tomatoes have separate labels on featured titles, cards and details. Missing/invalid scores show a dash, with the reason in details. TMDB votes are never passed off as IMDb or Rotten Tomatoes. Some titles, especially series, have no Rotten Tomatoes score in OMDb. A missing key, exhausted free quota or ratings outage does not block catalog results. Top rated browsing still sorts by clearly identified **TMDB votes**.

**Continuous browsing:** results append automatically near the bottom, with no Previous/Next controls or batch counters. Mixed movie/TV requests retain both complete source batches rather than discarding half. Duplicate movie/series IDs are suppressed, and changing a search/filter cancels stale work and resets its cursor. Catalog limits still apply (up to TMDB's 500 source pages); this is continuous loading, not an infinite catalog. After three consecutive batches with no new filtered matches, automatic requests pause with **Keep looking**, preventing an unbounded background scan. A failed append keeps current titles and provides **Try again** at the same cursor.

The native ListView recycles three-card rows so decoded posters are attached only to the visible/recycled views, plus the featured title. Artwork has two workers, response/dimension limits and an 8 MiB memory-only bitmap cache; rebinding a card cancels its old artwork request. Availability keeps four workers and a 35-second deadline per source batch. Ratings are requested as cards are bound, using two workers and the existing bounded 120-title/15-minute cache. No image cache is saved to disk. Saved titles remain capped at 100 with their last availability timestamp.

**Search on demand:** the sidebar Search action expands the input bar; Search submission or Close collapses it. Browsing opens without the search bar. Companion searches use the same path. App banners, artwork, controls and focus outlines now use rounder corners.

Offline tests cover feed cursors, deduplication, sparse batches, the upstream end, full mixed-source batches, active search filters, provider failures, exact IMDb IDs, ratings validation, quotas and cancellation. Live TV checks with owner-configured keys exercised automatic loading to 160 titles, search-bar expansion/collapse and a search rating filter. See [validation](validation.md#explore-0111) for details and limits.

## Spotify vibes

The separate Home tile opens a compact native panel. The regular Spotify logo tile still launches Spotify directly. Six default vibes open verified public Spotify playlists: Deep Focus, Chill Hits, Beast Mode, Jazz Vibes, Afternoon Acoustic and Sleep. **Edit vibes** can assign a verified Spotify playlist, album, artist or track link/URI. Links stay in private preferences; opening a link does not guarantee autoplay or exact TV-app navigation.

Optional playback controls use Spotify's actual local Android media session. Android requires notification-listener access, a broader permission than music control. The panel explains this before opening the access setting. The implementation ignores notification content, reads only Spotify title/artist/state, stores no listening history, downloads no artwork, and registers callbacks only while the panel is open. Controls are disabled unless the session advertises them. Another device's Spotify session is not automatically a session on this TV.

Some Fire OS versions omit the standard notification-access UI. After explicit owner consent, an authorized ADB shell can enable only Vista's component using the supported Android notification command:

```sh
adb -s YOUR_ADB_SERIAL shell cmd notification allow_listener com.griffin.solhome/.SpotifyMediaListener
```

Revoke it using `disallow_listener` with the same component. Do not enable this silently during installation. No Spotify OAuth credential, API/Connect integration or privileged media-control permission is bundled.

Default playlist targets were checked against Spotify's public oEmbed metadata. A generic “Chill” search resolved to a particular song in the TV test, so the shipped defaults use explicit playlist IDs instead. [Deep Focus](https://open.spotify.com/playlist/37i9dQZF1DWZeKCadgRdKQ), [Chill Hits](https://open.spotify.com/playlist/37i9dQZF1DX4WYpdgoIcn6), [Beast Mode](https://open.spotify.com/playlist/37i9dQZF1DX76Wlfdnj7AP), [Jazz Vibes](https://open.spotify.com/playlist/37i9dQZF1DX0SM0LYsmbMT), [Afternoon Acoustic](https://open.spotify.com/playlist/37i9dQZF1DX4E3UdUs7fUx), [Sleep](https://open.spotify.com/playlist/37i9dQZF1DWZd79rJ6a7lp). Playlist contents can change; owners can replace the shortcuts locally.
