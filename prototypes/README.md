# Preserved development snapshots

These are authentic source/art snapshots retained during development and imported into Git on October 17, 2026. They are not a reconstructed original commit history, complete releases, or current build targets. No commits are backdated.

- `webview/`: Java WebView wrapper, HTML/CSS interface, and generated conservatory/pothos/monstera art from the first working dashboard.
- `native-static/`: the saved native Canvas source and alpine artwork before the app-logo grid and autumn animation.
- `image-prompts.txt`: built-in imagegen prompts for these historical assets.

Build the maintained implementation under `app/`. Use these snapshots to understand the rendering redesign described in `docs/validation.md`.
